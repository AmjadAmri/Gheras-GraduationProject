Docker app is running.
windows powershell:  
- docker start gheras-db
- docker ps

BACKEND:

1- cd backend
2- python -m venv .venv  
3- .venv\Scripts\Activate.ps1                                               
4- pip install -r requirements.txt (takes about 2 min)
5- python app.py migrate
6- python app.py runserver 8001                                                               

FRONTEND:

1- cd frontend
2- npm install
3- npm run dev
